    交换格式

    JSON 是无损主文件，保留 ID、复核状态与 metadata。CSV / 字幕仅用于交换，会丢失部分项目结构。

    字幕优先使用文字描述，描述为空时使用片段标签。时间按十进制四舍五入到毫秒，与命令行一致；亚毫秒区间、空白行和箭头分隔符会明确报错。SRT 另拒绝样式 / 转义标记；WebVTT 将文字转义。字幕不保留标签集合、ID 或复核状态。

    CSV 默认在可能被电子表格识别为公式的文本前添加单引号。需要原文时使用 JSON。
